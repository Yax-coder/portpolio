Lellall is a B2B procurement platform for restaurants, cafés, lounges and hotels: one place for ordering, vendor coordination, inventory, delivery, payment settlement and reporting. Live in Abuja with 7 active clients, 100 verified vendors, and ₦600M+ in gross transaction value processed.

<br />

== Responsibilties ==

- [x] Own the platform's architecture and technical decisions as CTO & Co-Founder.
- [x] Designed a 76-model PostgreSQL schema (Prisma) with 70+ migrations powering procurement, inventory and payments.
- [x] Built the React + TypeScript web app and a Flutter mobile app, backed by a NestJS API with JWT auth and real-time updates over WebSockets.
- [x] Integrated Paystack and Flutterwave billing, WhatsApp (Twilio) notifications, and AI-powered revenue forecasting (OpenAI, Google Vertex AI).
- [x] Lead a team of 10 across engineering, QA and support; run code reviews and mentor engineers.
