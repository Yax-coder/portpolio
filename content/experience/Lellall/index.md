# Lellall is a B2B procurement platform that centralizes ordering, vendor coordination, delivery and settlement for restaurants, hotels and food businesses.

### Highlights:

<br/>

- Live in Abuja with 7 active B2B clients and 100 verified vendors; ₦600M+ gross transaction value processed and 100% client retention over the last 6 months.
- Built the backend in TypeScript on NestJS and PostgreSQL (Prisma): a 76-model relational schema with 70+ migrations, JWT auth, role-based access, real-time updates over WebSockets and Swagger-documented REST APIs.
- Integrated Paystack and Flutterwave billing, WhatsApp (Twilio) and email notifications, and AI features (OpenAI, Google Vertex AI) for revenue forecasting and supply requests.
- Built the React + TypeScript web app and a Flutter mobile app; ship with Docker and GitHub Actions CI/CD to DigitalOcean.
- Own architecture and technical decisions; lead a team of 10 across engineering, QA and support, and run code reviews to keep the codebase maintainable.
